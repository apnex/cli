## Guardrails and closure

The whole-checkpoint copy retains identity; producer and recipient must not treat concurrent copies as one coordinated session.
Use distinct directories for alternative trials and evaluate a disposable copy so verification does not alter the submitted outcome.
Local executable transfer establishes only compatibility with the recorded platform and profile.
The manifest is an integrity inventory, not authentication.

The independent actor, targeted-edit comparison, and general reusable dependency composition remain unmeasured until their own observations exist.
The board stays active if only preparation and scripted rehearsal pass.
No implementation gate, deployment proof, external effects, or fresh-actor result is claimed from this audit.

## Mechanics, rationale, and consequence

### Mechanics

Tie each claimed property to a discriminating observation and keep unrun comparisons visible in the milestone record.

### Rationale

This experiment is useful only if it can distinguish portable structured continuation from a producer replaying its own answer.

### Consequence of violation

The evaluation would confirm its own preparation instead of testing the project's central claim.
