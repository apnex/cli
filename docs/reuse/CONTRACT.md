Preparation duration includes construction, copying, hashing, and manifest creation.
Receiver duration includes verification, first-copy publication, process lifetime, and input waiting.
Nested process durations overlap receiver durations and must not be added to them.
Compilation is measured separately in the execution log; none of these times measures model reasoning between receiver invocations.

Scripted rehearsal establishes executability and oracle sensitivity.
It is not a comparative agent experiment, token-saving measurement, or independent certification.
Source-asset creation costs are retained even when an incremental reuse result excludes them; both views must be shown.

## Mechanics, rationale, and consequence

### Mechanics

Freeze requirements, prepare artifacts through the real CLI, run an independent continuation, and evaluate against an oracle the recipient did not author.

### Rationale

The experiment measures whether existing structured work is sufficient to continue; missing mechanisms should emerge from its actual failures.

### Consequence of violation

A scripted success, compact specification, or internally valid mock could be promoted into a claim about agent capability or reusable composition without the required observation.
