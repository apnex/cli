## Findings retained during implementation

The first test build used the wrong completion-result accessor; the compiler rejected the fixture.
The next run exposed a tagged-enum decoding path incompatible with the exact raw JSON value model.
Definition tags now select strict payload shapes directly from their original bytes.
The fault scenario in that failing run did not reach its target and was reported as `INVALID`, not as fault evidence.

The following run observed `1e+400` for an argument supplied as `1e400`.
The [contract correction](CONTRACT.md#correction-machine-scalar-representation) retains the task's exact-value requirement and reuses typed constructors at the machine boundary.
Discovery carries exact binding-program text for the same reason.
Failed runs remain under [CLI-003 evidence](../evidence/cli-003/) alongside later runs.
