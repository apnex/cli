# Output-view definition reference

`cli-definition-v3` retains the existing contexts, commands, bindings, and initial state, and adds a required nonempty `views` map.
Each command may name a view through its optional `view` string.
The view must exist in that definition.
Old v1/v2 definitions omit these fields; explicit null and unknown fields are rejected.
View names and column IDs follow the existing CLI identifier rules.

A v3 definition can be plain or carry assembly provenance.
A component can embed a plain v3 definition; assembly prefixes view names and command references with the mount name.
Expression paths still address the returned document.

The [AGP recipe](acceptance/agp.commands) is a complete command-based construction example.
Its [export](acceptance/agp.json) is generated by running that recipe.
The [contract](CONTRACT.md) owns execution and recovery guarantees.

## View and column fields

| Object | Required fields | Meaning |
|---|---|---|
| View | `help`, `require`, `rows`, `columns` | Nonempty help text, an input predicate, a row-array expression, and an ordered array of columns. |
| Column | `id`, `heading`, `value`, `format` | Unique stable ID, nonempty heading, typed value expression, and display format. |

The requirement must yield boolean true before rows are evaluated.
The row expression must yield an array.
Columns evaluate in array order for each row.
Projected rows are objects keyed by column ID; the ordered `columns` array and `display_rows` preserve display order.
An absent value omits the projected field, while explicit null remains null.
Both display as an empty plain cell.

## Expressions

Every expression is an object with `op` and exactly the fields specified below.
There is no embedded script, shell command, jq source, implicit cast, clock, or external read.
Each nested expression uses the same vocabulary.

| `op` | Other required fields | Evaluation |
|---|---|---|
| `root` | `path` | Read the complete result document. |
| `row` | `path` | Read the current output row; valid only in column expressions. |
| `item` | `path` | Read the current predicate item; valid inside `first`/`any` predicates. |
| `literal` | `value` | Preserve the given JSON value and exact number spelling. |
| `coalesce` | `values`, `skip_false` | First value that is neither missing nor null; skip false only when explicitly enabled. All absent returns missing. |
| `eq` | `left`, `right` | Exact document equality, including numeric token spelling; missing equals missing. |
| `and` | `values` | Boolean conjunction with short-circuit evaluation. |
| `is` | `value`, `type` | Test `object`, `array`, `string`, `number`, `boolean`, `null`, or `missing`. |
| `if` | `condition`, `then`, `else` | Evaluate only the selected branch; condition must be boolean. |
| `first` | `input`, `where`, `path` | From the first array item whose predicate is true, read the given path. Non-array input or no match returns missing. |
| `any` | `input`, `where` | True when any array item matches; non-array input is an error. |
| `concat` | `values` | Concatenate value text; missing/null become empty text, strings remain strings, other types use exact compact JSON. |
| `entries` | `input` | Convert an object into rows containing `key` and `value`, in lexical key order; reject non-objects and more than 4096 members. |
| `length` | `input` | Return the number of members in an object or elements in an array; reject other types. |

Paths are arrays of typed segments: an object containing either `key` with a string or `index` with a nonnegative integer.
An empty path selects the scope itself.
A missing member, out-of-bounds index, or incompatible parent type evaluates to missing.
Numeric-looking keys remain object keys.
Every predicate sees the same root and outer row; a nested predicate rebinds item to its own current element.
Conditions and predicates require booleans; strings and numbers are not treated as truth values.

AGP's selected-route marker uses `any` against the root selected array while retaining the candidate row.
The hold TTL uses `first` with predicates on timer name and state.
Domain field names and fallback choices live in the definition, not in Rust source.

## Display formats

The format is an object with `kind` and exactly the following additional fields.

| `kind` | Additional fields | Display |
|---|---|---|
| `plain` | None | String text, empty for missing/null, otherwise exact compact JSON. |
| `duration_hms` | `fallback` | Numeric milliseconds floored to seconds, then total hours/minutes/seconds; hours do not wrap at 24. |
| `seconds_ceil` | `fallback` | Numeric milliseconds rounded up to seconds, clamped at zero, with `s` suffix. |
| `join` | `separator`, `fallback` | Join array elements using plain value text. |

Fallback and separator fields are strings.
A non-number duration or non-array join uses its fallback.
Negative elapsed duration rejects; negative remaining duration clamps to zero.
Duration arithmetic reads exact decimal tokens, including exponent notation, without floating-point conversion.
It uses only the supplied value, so a retained result does not acquire a freshly inferred age.

Display cleaning replaces control characters and directional formatting characters U+202A through U+202E and U+2066 through U+2069 with spaces, and doubles backslashes.
The original document and typed projected values remain untouched.
Headings use the same cleaning.
Unicode display widths determine padding; columns use two separating spaces and retain full cell contents.
There is no color, terminal-width truncation, or locale-dependent formatting in this version.

## Bounds and errors

| Bound | Limit |
|---|---|
| Views per definition | 64 |
| Columns per view | 32 |
| Expression nesting | Root depth 0 through 16 |
| Expression nodes per view | 2048 across requirement, rows, and columns |
| List operands | 1 through 32 |
| Path segments | 64 |
| Result rows | 4096 |
| Evaluation work | 100000 expression, traversal, and iteration steps |
| Cumulative copied value JSON | 16 MiB per presentation |
| Concatenated string | 64 KiB |
| Complete serialized presentation | 4 MiB; padding is checked before allocation |
| Duration integer seconds | 4096 digits including a rounding carry |

Existing definition/document/scalar and response bounds also apply.
These are explicit rejection limits rather than streaming guarantees.
`INVALID_OUTPUT_VIEW` rejects malformed expression/column definitions.
`OUTPUT_VIEW_INPUT` identifies incompatible result data, and `OUTPUT_VIEW_LIMIT` identifies exhausted presentation bounds.
Cell evaluation errors identify the view, zero-based row, and column ID.
Definition parsing or document limits may reject earlier with their existing error codes.

`:views` exposes definitions; generated command help advertises its selected view.
`:render <view>` completes declared view IDs and renders the retained invocation without effects.
`cli render --json` emits `source: document_preview` and a presentation, without opening an invocation session.
For invocation rendering, `--json` exposes `result.presentation.status` separately from the invocation outcome; a failed presentation never rewrites success as a rejected command.
